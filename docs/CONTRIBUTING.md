# Contributing to ChIT

## The One Rule

Contributors must not use AI tools in the creation of code for ChIT.

## A Recommendation

I (soolar) do not frequently check Github notifications. If you want your Pull Request reviewed, I
strongly recommend that you notify me via Discord on the [#chit-character-info-toolbox](https://discord.gg/CnpK8kByry)
channel of the Ascension Speed Society server.
